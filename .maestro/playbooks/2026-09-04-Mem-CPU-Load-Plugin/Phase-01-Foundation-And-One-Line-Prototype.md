# Phase 01: Foundation and One-Line Prototype

This phase turns the empty `herdr-mem-cpu-load` repository into a working Rust crate that samples CPU, memory, and load average on Linux and prints the classic `tmux-mem-cpu-load` one-line status (for example `2885/7987MB [|||||     ]  51.2% 2.11 2.35 2.44`). It ports the C++ sampling and formatting logic from `/home/matt/src/tmux-mem-cpu-load` into a clean module layout with a platform abstraction, pure (testable) parsers and renderers, unicode block-bar rendering, a first `herdr-plugin.toml`, and unit tests. Everything here runs on the local Linux machine with no user input; by the end, `cargo run --release` prints a live system status line and the crate is ready for the herdr daemon mode added in Phase 02.

- [x] Implement the Linux backend in `src/sys/linux.rs`, porting `/home/matt/src/tmux-mem-cpu-load/linux/cpu.cc` and `linux/memory.cc` exactly, but with the parsing separated into pure functions that take `&str` so they can be unit tested:
  - `pub(crate) fn parse_proc_stat(contents: &str) -> Result<CpuTimes, SysError>`: take the first line, require it to start with `cpu ` (aggregate line), parse the first four numeric fields as user, nice, system, idle. Ignore the remaining fields (iowait, irq, softirq, steal) to match the original formula.
  - `pub(crate) fn parse_meminfo(contents: &str) -> Result<MemoryStatus, SysError>`: values in `/proc/meminfo` are in kB. Compute the htop-style formula from the original: `used = MemTotal - MemFree - Buffers - Cached - SReclaimable + Shmem`. Parse each `Key: value kB` line by splitting on `:` and taking the first whitespace token of the remainder. Missing optional keys (`Shmem`, `SReclaimable`) count as 0; missing `MemTotal` or `MemFree` is an error. Convert kB to bytes (multiply by 1024) for the `MemoryStatus` fields.
  - `cpu_times()` reads `/proc/stat`, `memory_status()` reads `/proc/meminfo`, both via `std::fs::read_to_string`.
  - `load_averages()` calls `libc::getloadavg` with a `[f64; 3]` buffer; treat a return value less than 3 as an error.
  - `cpu_count()` calls `libc::sysconf(libc::_SC_NPROCESSORS_ONLN)` and falls back as described in the abstraction when the result is not positive.
